Part 3: 衛星資料 API 實作

「從太空到你的電腦，只需要一個網址」

NASA POWER API Call JSON Data

🔌 什麼是 API？

API 就像「餐廳的菜單和服務生」：

  • 你（程式）不用自己去廚房做菜
  • 你只要看菜單（API 文件），告訴服務生你要什麼（發送請求）
  • 服務生就會把菜端給你（回傳資料）

📤 你給 API

地點（經緯度）+ 時間（日期範圍）+ 要什麼資料（溫度、降雨等）

📥 API 回你

一包 JSON 格式的衛星觀測資料

💡 簡單來說，API 就是「程式跟程式之間溝通的橋樑」。你不用了解 NASA 的衛星怎麼運作，只要會「點菜」就好！

🛰️ NASA POWER API 參數完全解析

以下是我們可以向 NASA POWER API 請求的衛星觀測資料參數：

參數代碼 中文說明 單位 資料來源
T2M 每日平均氣溫 °C 衛星+地面站
T2M_MAX 每日最高氣溫 °C 衛星+地面站
T2M_MIN 每日最低氣溫 °C 衛星+地面站
PRECTOTCORR 每日校正降雨量 mm/day 衛星觀測
RH2M 2公尺高相對濕度 % 衛星觀測
ALLSKY_SFC_SW_DWN 全天空地表日射量 MJ/m²/day 衛星觀測
WS2M 2公尺高風速 m/s 衛星觀測

💡 這些資料全部來自低軌衛星的觀測結果，由 NASA 整理成 API 免費提供！

🧩 自己動手組裝 API 網址

在寫程式之前，我們先學會「自己組裝」一個 API 網址。就像點餐一樣，你要決定三件事：

📍 地點在哪裡？

經度 longitude 和緯度 latitude，例如台南是 120.2 和 23.0

📅 要哪幾天？

開始日期 start 和結束日期 end，格式是 YYYYMMDD

📊 要什麼資料？

parameters 參數，例如 T2M 是氣溫、RH2M 是濕度

組裝公式

https://power.larc.nasa.gov/api/temporal/daily/point  ← 主網址（固定不變）
  ?parameters=T2M,T2M_MAX,T2M_MIN,PRECTOTCORR,RH2M   ← 你要的資料
  &community=AG                                        ← 資料類別
  &longitude=你的經度                                   ← 例：120.2
  &latitude=你的緯度                                    ← 例：23.0
  &start=開始日期                                       ← 例：20260201
  &end=結束日期                                         ← 例：20260207
  &format=JSON                                         ← 回傳格式

🎯 練習時間！請在瀏覽器中試試看：把上面的「你的經度」「你的緯度」換成你學校或家裡的座標，組裝出自己的 API 網址，貼到瀏覽器看看結果！

✅ 搞懂這個公式，等一下寫程式時就只是讓程式「自動幫你組裝這串網址」而已！

// === 📍 預設地點（使用者可在 LINE 中輸入城市名稱查詢）===

  '台中': { lat: 24.1, lon: 120.7 },
  '台南': { lat: 23.0, lon: 120.2 },
  '高雄': { lat: 22.6, lon: 120.3 },
  '花蓮': { lat: 24.0, lon: 121.6 },
  '墾丁': { lat: 21.9, lon: 120.8 },

⚠️ 請把 LINE_TOKEN 換成你自己在 Part 2 取得的 Channel Access Token！引號不要刪掉！

💡 新架構不需要 User ID 和固定經緯度了！使用者在 LINE 聊天中輸入城市名稱（如「台南」）或自訂座標（如「23.0, 120.2」），機器人就會自動查詢並回覆！

⚡ 懶人福音！不想一段一段貼？用 GAS 程式碼生成器 填入你的 Token，一鍵生成完整程式碼！

💻 取得衛星資料（第二段：核心函式）

繼續在下方貼上以下程式碼：

// === 🛰️ 取得 NASA 衛星觀測資料 ===
function getSatelliteData(lat, lon) {
  // 計算日期範圍（最近 7 天）
  const today = new Date();
  const end = Utilities.formatDate(today, 'GMT+8', 'yyyyMMdd');
  const weekAgo = new Date(today.getTime() - 7 * 24 * 60 * 60 * 1000);
  const start = Utilities.formatDate(weekAgo, 'GMT+8', 'yyyyMMdd');

  // 組合 API 網址
  const url = 'https://power.larc.nasa.gov/api/temporal/daily/point' +
    '?parameters=T2M,T2M_MAX,T2M_MIN,PRECTOTCORR,RH2M' +
    '&community=AG' +
    '&longitude=' + lon +
    '&latitude=' + lat +
    '&start=' + start +
    '&end=' + end +
    '&format=JSON';

  // 發送請求，取得資料
  const response = UrlFetchApp.fetch(url);
  const data = JSON.parse(response.getContentText());

  return data;
}

💡 逐行解釋：

  • Utilities.formatDate → GAS 內建的日期格式化工具
  • UrlFetchApp.fetch → GAS 的 HTTP 請求方法（就像瀏覽器打開網址）
  • JSON.parse → 把文字轉換成程式可以讀取的格式

🧪 測試看看！API 回傳什麼？

先加一個測試函式，看看 API 回傳的資料長什麼樣：

// === 🧪 測試函式 ===
function testAPI() {
  const data = getSatelliteData(LATITUDE, LONGITUDE);
  Logger.log('=== 衛星資料回傳結果 ===');
  Logger.log(JSON.stringify(data, null, 2));
}

操作步驟

  1. 把以上程式碼也貼到 GAS 編輯器中
  2. 在上方函式選單中，選擇 testAPI
  3. 點擊 ▶️ 執行按鈕
  4. 第一次會要求授權，點選「審查權限」→ 選擇你的帳號 → 「允許」
  5. 點擊「查看」→「記錄」查看結果

✅ 如果你看到一大串 JSON 資料，恭喜！你已經成功從低軌衛星取得資料了！🎉

📋 讀懂 API 回傳的 JSON 資料

API 回傳的資料結構大致如下（簡化版）：

{
  "geometry": {
    "coordinates": [120.2, 23.0]
  },
  "properties": {
    "parameter": {
      "T2M": {
        "20260201": 18.52,
        "20260202": 19.31,
        "20260203": 17.89
      },
      "PRECTOTCORR": {
        "20260201": 0.12,
        "20260202": 5.67,
        "20260203": 0.01
      }
    }
  }
}

結構解析

  • geometry.coordinates → 你查詢的經緯度
  • properties.parameter → 所有觀測參數
  • T2M → 每天的平均氣溫
  • 日期格式：YYYYMMDD

💡 重點就是：data.properties.parameter.T2M["20260201"] 就能取得 2/1 的溫度！
