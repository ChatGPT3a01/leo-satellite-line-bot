GAS 程式碼生成器

填入 LINE Token，一鍵生成互動式衛星氣象聊天機器人

💬 這個機器人可以做什麼？

你的 LINE Bot 會變成一個互動式衛星氣象查詢機器人：

📱 你在 LINE 輸入「台南」
⬇️
🤖 Bot 自動呼叫 NASA 衛星 API 取得台南的氣象資料
⬇️
📨 Bot 立刻回覆你「衛星觀測日報」

💬 LINE 對話長這樣

🛰️ 衛星觀測日報 📍 地點：25.03°N, 121.57°E ...

💡 支援兩種查詢方式：
① 輸入地點名稱：台北、台南、高雄、台中、東京...
② 輸入經緯度座標：例如 25.03, 121.57

📝 填入你的 LINE Token

💡 只需要填 Channel Access Token 這一個值！經緯度不用填，使用者直接在 LINE 對話中輸入地點就可以了。

✅ 程式碼已生成！

🚀 接下來：部署你的機器人

Step A：把程式碼貼到 GAS

  1. 開啟你在 Part 2 建立的 Google Sheet「低軌衛星LINE推播 - 查詢紀錄」
  2. 點擊上方選單 「擴充功能」 → 「Apps Script」
  3. 全選編輯器內容（Ctrl+A），貼上剛才複製的程式碼（Ctrl+V）
  4. 按 Ctrl+S 儲存

Step B：部署為網路應用程式

  1. 點擊右上角的 「部署」 → 「新增部署作業」
  2. 左邊類型選擇 ⚙️ → 「網頁應用程式」
  3. 說明填：衛星氣象機器人（隨意）
  4. 「執行身分」選：我
  5. 「誰可以存取」選：所有人
  6. 點擊 「部署」
  7. 第一次會要求授權，點選「授予存取權」→ 選你的帳號 → 「進階」→ 「前往（不安全）」→ 「允許」
  8. 部署完成！複製「網頁應用程式網址」（很重要！）

⚠️ 那串網址長得像：
https://script.google.com/macros/s/AKfycbx.../exec
請先複製保存！

Step C：設定 LINE Webhook

  1. 回到 LINE Developers，進入你的 Channel 設定頁
  2. 點上方的 「Messaging API」 分頁
  3. 找到 「Webhook URL」，點擊 「Edit」
  4. 把剛才複製的 GAS 網址貼上去，點 「Update」
  5. 打開 「Use webhook」 開關（變成綠色）
  6. 點擊 「Verify」 按鈕，看到 「Success」 就完成了！

⚠️ 同一個頁面，請確認：
• 「Auto-reply messages」 設定為 Disabled（關閉自動回覆）
• 不然 LINE 會發重複的預設訊息

Step D：測試你的機器人！

  1. 打開手機 LINE，找到你的 Bot
  2. 輸入 「台南」 送出
  3. 等幾秒鐘... Bot 就會回覆衛星觀測日報！🎉

🎉 恭喜！你的衛星氣象聊天機器人完成了！
