🛰️ 我們要串接哪個 API？怎麼串？

我們要串接的是 NASA POWER API（美國太空總署提供的低軌衛星觀測資料 API）

🌐 官方網站：https://power.larc.nasa.gov/

📌 串接流程（超簡單，只有 3 步）

❶ 組裝 API 網址

把「我要什麼資料」「哪個地點」「哪段時間」填進網址裡

❷ 發送請求

用瀏覽器打開網址（手動測試）
或用程式自動發送（正式串接）

❸ 取得 JSON 資料

NASA 回傳一包 JSON 格式的衛星觀測數據，直接拿來用！

⚠️ 跟一般 API 不一樣的地方：

  • ❌ 不用去官網註冊帳號
  • ❌ 不用申請 API Key
  • ❌ 不用付費
  • ✅ 只要知道 API 網址，直接呼叫就有資料！

💡 API 網址入口（完整範例，可直接貼到瀏覽器試試）：
https://power.larc.nasa.gov/api/temporal/daily/point?parameters=T2M,T2M_MAX,T2M_MIN,PRECTOTCORR,RH2M,ALLSKY_SFC_SW_DWN,WS2M&community=AG&longitude=121.5&latitude=25.03&start=20250101&end=20250107&format=JSON

下一頁我們馬上來試！

🖐️ 動手試試看！用瀏覽器呼叫 API

⚠️ 這是最重要的一步！請跟著做

  1. 打開瀏覽器（Chrome 或 Edge）
  2. 複製下方整段網址（不要漏掉任何字）
  3. 貼到瀏覽器的網址列
  4. 按下 Enter
  5. 你會看到一大串文字，那就是低軌衛星觀測到的資料！

👇 複製這串網址

https://power.larc.nasa.gov/api/temporal/daily/point?parameters=T2M,T2M_MAX,T2M_MIN,PRECTOTCORR,RH2M,ALLSKY_SFC_SW_DWN,WS2M&community=AG&longitude=120.2&latitude=23.0&start=20260201&end=20260207&format=JSON

🎉 如果你看到一堆大括號和數字，恭喜！你剛剛成功用「低軌衛星觀測資料 API」取得了台南地區一週的氣象資料！

💡 看不懂那些文字沒關係！接下來我們會用程式幫你「翻譯」成看得懂的內容。

🔍 API 網址長什麼樣？一段一段拆開看

剛才那串網址看起來很長，其實是「主網址」加上「你的需求」組合而成：

主網址：
https://power.larc.nasa.gov/api/temporal/daily/point

加上你的需求（用 ? 和 & 連接）：

?parameters=T2M,...,ALLSKY_SFC_SW_DWN,WS2M           ← 要哪些觀測資料
&community=AG                                        ← 資料類別（農業）
&longitude=120.2                                     ← 經度（台南）
&latitude=23.0                                       ← 緯度（台南）
&start=20260201                                      ← 開始日期
&end=20260207                                        ← 結束日期
&format=JSON                                         ← 回傳格式
參數 意思 你可以改什麼
parameters 想要哪些觀測資料 T2M=氣溫, PRECTOTCORR=降雨, RH2M=濕度, ALLSKY_SFC_SW_DWN=日照量, WS2M=風速
community 資料應用領域 AG=農業（最常用）
longitude 經度 例：121.5（台北）、120.2（台南）
latitude 緯度 例：25.0（台北）、23.0（台南）
start / end 日期範圍 格式：YYYYMMDD（例：20260210）
format 回傳格式 JSON（固定用這個就好）

💡 試試看！把經緯度改成你家附近的座標，再貼到瀏覽器看看會得到什麼資料！（去 Google Maps 按右鍵就能看到座標）

📱 LINE Messaging API 設定（步驟 1/4）

第一步：建立 LINE Developers 帳號
  1. 打開瀏覽器，前往 LINE Developers 網站
  2. 網址：https://developers.line.biz/
  3. 點擊右上角「Log in」
  4. 使用你的 LINE 帳號登入
  5. 如果是第一次，會要求你建立開發者帳號，填寫姓名和 Email 即可

💡 如果登入遇到問題，可以先用手機 LINE 掃描 QR Code 登入

📱 LINE Messaging API 設定（步驟 2/4）

第二步：建立 Provider 和 Channel
  1. 登入後，點擊「Create a new provider」
  2. Provider 名稱隨意填（例如：我的衛星專案）
  3. 建立完成後，點擊「Create a Messaging API channel」
  4. 填寫以下資訊：
    • Channel name：衛星觀測推播（或任意名稱）
    • Channel description：低軌衛星資訊推播
    • Category：選擇 Education
    • Subcategory：選擇任意
  5. 勾選同意條款，點擊「Create」

⚠️ Channel name 建立後就無法更改，請想好再填！

📱 LINE Messaging API 設定（步驟 3/4）

第三步：取得 Channel Access Token
  1. 建立 Channel 完成後，進入 Channel 設定頁面
  2. 點擊上方的「Messaging API」分頁
  3. 滾動到最下方，找到「Channel access token (long-lived)」
  4. 點擊「Issue」按鈕
  5. 產生一串很長的 Token（一串英數字）
  6. ⚠️ 請立刻複製並貼到記事本保存！

同時取得 User ID

  1. 在同一頁面的「Basic settings」分頁
  2. 找到「Your user ID」（以 U 開頭的一串字）
  3. 同樣複製保存

⚠️ Token 和 User ID 非常重要，就像你的密碼一樣，請妥善保管！不要外流！

📱 LINE Messaging API 設定（步驟 4/4）

第四步：加入你的 LINE Bot 好友
  1. 在 Channel 設定頁面，找到「Messaging API」分頁
  2. 找到上方的 QR Code
  3. 用手機 LINE 掃描這個 QR Code
  4. 加入你剛建立的 Bot 為好友
  5. 完成！之後程式推播的訊息就會從這個 Bot 發送到你的 LINE

🎉 恭喜！LINE 的部分設定完成了！你現在有兩個重要的東西：
① Channel Access Token    ② Your User ID

💻 建立 Google Sheet + Apps Script 專案

  1. 打開瀏覽器，前往 Google Sheets，用你的 Google 帳號登入
  2. 點擊「+ 空白試算表」建立新的試算表
  3. 將試算表命名為「低軌衛星LINE推播 - 查詢紀錄」
  4. 在第一列（A1～H1）輸入表頭：查詢時間、地點、氣溫(°C)、降雨量(mm)、濕度(%)、日照量(MJ/m²)、風速(m/s)、查詢者
  5. 點擊上方選單 「擴充功能」 → 「Apps Script」
  6. 會開啟 Apps Script 編輯器，點擊左上角「未命名的專案」，改名為「低軌衛星LINE推播」
  7. 你會看到程式編輯器，裡面有 function myFunction() { }
  8. 全部刪掉，等一下我們會貼上新的程式碼

💡 為什麼要從 Google Sheet 進入？
這樣 Apps Script 會和試算表綁定，程式碼可以自動把每次的查詢紀錄寫入試算表，方便你蒐集和分析資料！

🎉 環境全部準備完成！我們有了：
✅ NASA API（不用設定）
✅ LINE Bot Token
✅ Google Sheet（自動蒐集查詢紀錄）
✅ GAS 程式環境（綁定試算表）
