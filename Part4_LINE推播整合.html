🔄 把數字變成「人話」

衛星回傳的是數字，但我們要讓任何人都能看懂。以下是轉譯規則：

資料 條件 轉譯結果
氣溫 > 30°C 🔥 高溫炎熱
氣溫 20-30°C ☀️ 溫暖舒適
氣溫 10-20°C 🍂 涼爽
氣溫 < 10°C ❄️ 寒冷
降雨 > 10mm 🌧️ 有明顯降雨
降雨 1-10mm 🌦️ 少量降雨
降雨 < 1mm ☀️ 無降雨
濕度 > 80% 💧 潮濕
濕度 40-80% 🌤️ 舒適
濕度 < 40% 🏜️ 乾燥

💻 資料解讀函式 interpretData

這個函式負責將衛星數據轉換成使用者能看懂的訊息，並加入生活建議分析：

// === 📊 解讀衛星資料，轉成人看得懂的話 ===
function interpretData(data, locationName) {
  const params = data.properties.parameter;
  const dates = Object.keys(params.T2M);
  const latestDate = dates[dates.length - 1];

  const temp = params.T2M[latestDate];
  const tempMax = params.T2M_MAX[latestDate];
  const tempMin = params.T2M_MIN[latestDate];
  const rain = params.PRECTOTCORR[latestDate];
  const humidity = params.RH2M[latestDate];

  // 氣溫判讀
  let tempStatus = '';
  if (temp > 30) tempStatus = '高溫炎熱 🔥';
  else if (temp > 20) tempStatus = '溫暖舒適 ☀️';
  else if (temp > 10) tempStatus = '涼爽 🍂';
  else tempStatus = '寒冷 ❄️';

  // 降雨判讀
  let rainStatus = '';
  if (rain > 10) rainStatus = '有明顯降雨 🌧️';
  else if (rain > 1) rainStatus = '少量降雨 🌦️';
  else rainStatus = '無降雨 ☀️';

  // 生活建議分析
  let analysis = [];
  if (temp <= 15) analysis.push('氣溫偏低，建議穿著保暖衣物');
  else if (temp <= 22) analysis.push('氣溫涼爽，建議攜帶薄外套');
  else if (temp >= 33) analysis.push('高溫警戒，注意防曬補水');

  if (tempMax - tempMin > 10) analysis.push('日夜溫差大（' +
    (tempMax - tempMin).toFixed(1) + '°C），早晚記得加衣');

  if (rain > 10) analysis.push('降雨明顯，請攜帶雨具，避免戶外活動');
  else if (rain > 1) analysis.push('可能有零星降雨，建議帶傘備用');
  else analysis.push('無降雨，適合戶外活動');

  if (humidity > 80) analysis.push('濕度偏高（' +
    humidity.toFixed(0) + '%），體感較悶熱');
  else if (humidity < 40) analysis.push('空氣乾燥（' +
    humidity.toFixed(0) + '%），注意保濕');

  // 組合訊息
  const message = '\n🛰️ 衛星觀測日報' +
    '\n━━━━━━━━━━━━' +
    '\n📍 地點：' + locationName +
    '\n📅 日期：' + latestDate +
    '\n━━━━━━━━━━━━' +
    '\n🌡️ 氣溫：' + temp.toFixed(1) + '°C（' + tempStatus + '）' +
    '\n📊 最高/最低：' + tempMax.toFixed(1) + '°C / ' +
      tempMin.toFixed(1) + '°C' +
    '\n💧 降雨量：' + rain.toFixed(1) + ' mm（' + rainStatus + '）' +
    '\n💨 相對濕度：' + humidity.toFixed(0) + '%' +
    '\n━━━━━━━━━━━━' +
    '\n💬 衛星資料分析：' +
    '\n' + analysis.map(a => '• ' + a).join('\n') +
    '\n━━━━━━━━━━━━' +
    '\n📡 資料來源：NASA POWER（低軌衛星觀測）';

  return message;
}

💡 跟之前不同的是：新增了「💬 衛星資料分析」區塊，根據氣溫、降雨、濕度自動產生生活建議，讓使用者一看就懂！

📲 Webhook 接收 + LINE 回覆函式

使用者在 LINE 發送訊息後，LINE 會把訊息轉發到我們的 GAS Web App。以下是接收和回覆的函式：

// === 📨 接收 LINE Webhook 事件 ===
function doPost(e) {
  const data = JSON.parse(e.postData.contents);
  const events = data.events;

  for (let i = 0; i < events.length; i++) {
    if (events[i].type === 'message' && events[i].message.type === 'text') {
      handleTextMessage(events[i]);
    }
  }

  return ContentService.createTextOutput('OK');
}

// === 📤 回覆 LINE 訊息 ===
function replyToLINE(replyToken, message) {
  const url = 'https://api.line.me/v2/bot/message/reply';
  const payload = {
    replyToken: replyToken,
    messages: [{ type: 'text', text: message }]
  };
  const options = {
    method: 'post',
    contentType: 'application/json',
    headers: { 'Authorization': 'Bearer ' + LINE_TOKEN },
    payload: JSON.stringify(payload)
  };
  UrlFetchApp.fetch(url, options);
}

逐行解釋

  • doPost(e) → GAS 的 Webhook 入口，LINE 會自動呼叫
  • e.postData.contents → LINE 傳來的訊息內容
  • ContentService.createTextOutput('OK') → 回傳 OK 讓 LINE 知道收到了
  • replyToLINE → 使用 Reply API（不是 Push API），用 replyToken 回覆

⚠️ Push API vs Reply API 差異：Push 是「主動推送」給指定 User ID；Reply 是「回覆」使用者的訊息，用 replyToken。互動式機器人用 Reply API！

🤖 處理使用者訊息

這個函式負責判斷使用者輸入的是城市名稱還是自訂座標，然後查詢衛星資料：

// === 🤖 處理使用者的文字訊息 ===
function handleTextMessage(event) {
  const text = event.message.text.trim();
  const replyToken = event.replyToken;

  // 檢查是否為預設城市名稱
  if (LOCATIONS[text]) {
    const loc = LOCATIONS[text];
    const data = getSatelliteData(loc.lat, loc.lon);
    const message = interpretData(data, text);
    replyToLINE(replyToken, message);
    return;
  }

  // 檢查是否為自訂座標（例如：23.0, 120.2）
  const coordMatch = text.match(/^([\d.-]+)\s*[,，\s]\s*([\d.-]+)$/);
  if (coordMatch) {
    const lat = parseFloat(coordMatch[1]);
    const lon = parseFloat(coordMatch[2]);
    const data = getSatelliteData(lat, lon);
    const message = interpretData(data, lat + '°N, ' + lon + '°E');
    replyToLINE(replyToken, message);
    return;
  }

  // 都不是 → 顯示使用說明
  replyToLINE(replyToken, getHelpMessage());
}

// === ❓ 使用說明 ===
function getHelpMessage() {
  return '🛰️ 低軌衛星觀測機器人\n' +
    '━━━━━━━━━━━━\n' +
    '📍 輸入城市名稱查詢，例如：\n' +
    '   台北、台中、台南、高雄\n' +
    '   花蓮、墾丁、東京、紐約\n\n' +
    '📐 或輸入自訂座標，例如：\n' +
    '   23.0, 120.2\n\n' +
    '🌏 支援全球任何地點！';
}

💡 處理邏輯：① 先檢查是不是預設城市名稱 → ② 再檢查是不是座標格式 → ③ 都不是就顯示使用說明。使用者完全不需要記任何指令！

🚀 部署為 Web App 並設定 Webhook

操作步驟

  1. GAS 編輯器 → 點擊右上角「部署」→「新增部署作業」
  2. 類型選擇「網頁應用程式」
  3. 說明填寫「低軌衛星 LINE Bot」
  4. 執行身分選「我」
  5. 誰可以存取選「所有人」
  6. 點擊「部署」→ 複製產生的「網頁應用程式網址」
  7. 回到 LINE Developers → 進入你的 Channel → Messaging API 分頁
  8. 在 Webhook URL 欄位貼上剛才的網址
  9. 點擊「Verify」確認連線成功
  10. 打開「Use webhook」開關
  11. 關閉「Auto-reply messages」和「Greeting messages」

🎉 部署完成！現在打開手機 LINE，對你的機器人發送「台南」試試看！

⚠️ 每次修改程式碼後，需要重新「部署」→「管理部署作業」→「編輯」→ 版本選「新版本」→「部署」

🔧 常見問題排除

⚠️ Webhook 驗證失敗

確認 GAS 部署為「所有人」可存取，確認網址正確貼上。若仍失敗，請重新部署一次新版本。

⚠️ 機器人沒回應

確認 Webhook URL 已設定、Use webhook 已開啟、Auto-reply 已關閉。可到 GAS 的「執行記錄」查看是否有錯誤訊息。

⚠️ 回覆 403 或 Token 錯誤

確認 LINE_TOKEN 正確，前後無空白。確保是從 LINE Developers 後台複製的 Channel Access Token。

❓ 第一次部署要求授權

這是正常的！點擊「審查權限」→ 選帳號 →「進階」→「前往...（不安全）」→「允許」即可。
